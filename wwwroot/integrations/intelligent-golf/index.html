Small installation. Central updates.

How it will fit into your club website.

  1. We prepare your club page

    A dedicated honours page is configured in Intelligent Golf, using your member-area access settings.

  2. One script brings the board to life

    The page references our centrally hosted JavaScript. It renders the honours board and adapts it to the available space.

  3. Your club chooses what members see

    Approved records are supplied to the protected page. Where that uses a page snapshot, the snapshot is refreshed when your club releases an update.

  4. Member links make it personal

    An approved connection between the signed-in member and the archive enables “My trophies”. New features can be maintained centrally.

For your website administrator: what goes on the page?

The intended installation uses a small page container and a versioned script reference. Per-club settings and approved records supply the content; the same renderer serves every club.

The simplest protected option keeps an approved honours snapshot within the restricted Intelligent Golf page itself. Existing login information can then choose a personal view of records the member is already authorised to see. A live private-data connection would need a verified server authentication mechanism.

A public board embedded in a protected page still has a public data endpoint. The members-only installation must protect the data and images as well as the surrounding page. The current public embed does not provide that member access control.

Before choosing the extra

What is included, and what comes next.

Do we need this to share our honours board?

No. A hosted public link, ordinary iframe/script embedding and winner search are included in the core archive. The annual extra is for managed Intelligent Golf installation and member features.

Is the Intelligent Golf plugin available now?

Not yet. The core board and public embed work today. The reusable member integration, club setup and protected data connection are still being prepared. Purchasing remains unavailable during that work.

Will members need another password?

The intended member-area experience uses their existing Intelligent Golf login. The final connection must be checked for your club’s website before activation.

What happens if we stop the annual subscription?

The managed integration service ends under its subscription terms. Your core Trophy Guru account, saved records and unused trophy credits remain separate.

Can members search the whole membership directory?

The member board is for approved award records. Private directory information and tools for matching inscriptions remain available only to authorised archive users.

Is this an official Intelligent Golf product?

This is a planned Trophy Guru integration for clubs using Intelligent Golf. No vendor endorsement or partnership is being claimed.
